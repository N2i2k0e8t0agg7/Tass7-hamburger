# Laundry Services Hamburger Menu (Mobile Responsive)
A responsive laundry service landing page with a pure CSS hamburger menu built using HTML and CSS only.

# 📌 Project Overview
This project demonstrates a responsive laundry website with a mobile hamburger navigation menu using only CSS pseudo-classes and positioning concepts.
The assignment focuses on:
- Mobile responsive design
- CSS `:focus` pseudo-class
- CSS sibling selectors
- Absolute positioning
- Pure CSS interaction without JavaScript
  
# 🚀 Features
- Responsive Landing Page
- Mobile Hamburger Menu
- Pure CSS Menu Toggle
- Slide-In Navigation Menu
- CSS Flexbox Layout
- Absolute Positioned Sidebar
- Smooth Transition Animation
- Mobile-First Responsive Design

# 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome Icons
- Flexbox
- CSS Media Queries

# 🎯 Assignment Requirements Covered
## ✅ Hamburger Menu Icon
- Visible only on mobile screens
- Hidden on desktop view

## ✅ Menu Positioning
- Positioned using `position: absolute`
- Opens from the right side

## ✅ CSS Focus Pseudo-Class
- Uses `button:focus`
- No JavaScript used

## ✅ Sibling Selector Usage
- Menu shown using:
  
```css
.menu-btn:focus + .mobile-menu
```

## ✅ Responsive Design
- Fully responsive mobile layout
  
# 📱 Responsive Behaviour
## Desktop View
- Normal navbar visible
- Hamburger menu hidden

## Mobile View
- Navbar links hidden
- Hamburger icon visible
- Menu slides from right side
